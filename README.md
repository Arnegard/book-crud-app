# Book CRUD App
# Michael Holst

Fullstack CRUD-app with FastAPI (backend) and React (frontend).

## Start backend
cd backend
pip install -r requirements.txt
python app.py

## Start frontend
cd frontend
npm install
npm run dev

## Endpoints
- POST /books
- GET /books
- GET /books/{id}
- PUT /books/{id}
- DELETE /books/{id}
